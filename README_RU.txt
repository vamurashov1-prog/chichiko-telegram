ЧИЧИКО ДЛЯ TELEGRAM — ПОЛНАЯ MVP-СБОРКА
========================================

ЧТО УЖЕ ЕСТЬ
- Вызов дуэли прямо в группе: /duel@RPSKO_bot @username (команда адресована боту, обычные сообщения он не читает).
- Альтернатива: ответить командой /duel@RPSKO_bot на сообщение соперника.
- Принять/отклонить может только адресованный игрок.
- После принятия оба игрока запускают одну общую Mini App-комнату кнопкой в сообщении.
- Одновременный скрытый выбор камня/ножниц/бумаги.
- Счёт до 3 побед, ничья не добавляет очко.
- Результаты раундов и финальный победитель публикуются в групповой чат.
- Проверка подписи Telegram initData на сервере; игрок не может ходить за другого.
- Комнаты сохраняются в data/rooms.json при перезапуске.

ВАЖНО: бот не может сам разместить приложение в интернете. Mini App требует публичный HTTPS-адрес. Сборка подготовлена для Node.js 20+ и хостинга с постоянным процессом и диском.

1. ПУБЛИКАЦИЯ ИСХОДНИКОВ
- Распакуй архив на компьютере. Локально Node.js устанавливать не нужно.
- На GitHub создай новый Private repository с именем chichiko-telegram.
- В репозитории нажми Add file → Upload files и перетащи ВСЁ содержимое папки chichiko_telegram_full (включая render.yaml и папки public, data; не загружай токен).
- Нажми Commit changes.
- Открой Render: https://dashboard.render.com/blueprints → New Blueprint Instance → подключи GitHub → выбери chichiko-telegram → Apply.
- Введи BOT_TOKEN в защищённое поле переменных окружения Render.
- В конфигурации задан Render Starter и постоянный диск 1 GB. Это платный постоянно работающий вариант; Render покажет стоимость до подтверждения.
- Build command: npm install. Start command: npm start. Node.js на сервере Render установится автоматически.

2. ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ НА ХОСТИНГЕ
BOT_TOKEN = новый токен из @BotFather (не публиковать и не присылать никому)
DISABLE_BOT = 0
PORT обычно задаёт хостинг автоматически.

3. ПОДКЛЮЧИ MINI APP В @BotFather
- Открой @BotFather → /mybots → выбери @RPSKO_bot.
- Bot Settings → Configure Mini App (или Main App) → Enable/Configure.
- Укажи публичный HTTPS URL сервиса, который выдаст Render после деплоя.
- Если BotFather попросит название, укажи ЧИЧИКО.
- Сохрани настройки. После этого ссылка https://t.me/RPSKO_bot?startapp=ID открывает комнату внутри Telegram.

4. ДОБАВЬ БОТА В ГРУППУ
- Открой @RPSKO_bot → профиль → Add to Group.
- Добавь его в нужный групповой чат.
- Права администратора не обязательны; боту достаточно отправки сообщений.

5. ИГРА
В групповом чате (важно: команда должна быть адресована боту, чтобы он получил её при включённом режиме приватности):
- /duel@RPSKO_bot @username
ИЛИ
- ответь на сообщение нужного игрока командой /duel@RPSKO_bot.
Не отключай Privacy Mode: так бот не будет читать обычную переписку группы.
Адресат нажимает «Принять вызов». Затем оба нажимают «Играть в ЧИЧИКО» в сообщении с вызовом.

6. ПРОВЕРКА
Открой https://ТВОЙ-APP-URL/health — должен вернуться JSON с ok:true и botConfigured:true.
Проверь также логи сервиса: строка «Telegram-бот подключён: @RPSKO_bot».

БЕЗОПАСНОСТЬ
- Старый токен, который ранее попал в переписку, нужно считать скомпрометированным. Используй только новый токен после /revoke в @BotFather.
- Не вставляй токен в исходники, README, публичные репозитории или чат. Вводи его только в защищённые Environment Variables хостинга.
- Если токен уже был опубликован где-либо ещё, снова отзови его и создай новый.

ОГРАНИЧЕНИЯ MVP
- Для вызова по username у соперника должен быть Telegram username. Если его нет, ответь командой /duel@RPSKO_bot на его сообщение; бот использует Telegram ID.
- Нет рейтингов, истории профиля, бафов и ставок.
- Для надёжного постоянного хранения нужен persistent disk у выбранного хостинга.
